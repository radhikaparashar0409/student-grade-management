# student-grade-management
A simple Python project to manage student marks and calculate grades.

##Features
Add student marks
Calculate student grades
Display student results

##Technologies Used
Python
## Requirements
Python 3.x

## Installation
1. Install Python 3.x on your computer.
2. Download or clone this repository.
3. Open the project folder in a terminal.

## How to Run
Run the following command in the terminal:

python main.py

## How to Use
1. Run the program.
2. Enter the student name when asked.
3. Enter the marks.
4. The program calculates the grade.
5. The student result is displayed.

## Example
Student Name: Rahul
Marks: 85
Grade: A

## Project Structure
- main.py - Main Python program
- README.md - Project documentation

## Limitations
- The current version handles one student at a time.
- Student records are not stored permanently.
